# 🍻 Piyachok (П'яничок) — Full-Stack Web Application

**Piyachok** — це сучасний, адаптивний вебдодаток у мінімалістичному стилі з інтуїтивно зрозумілою інфографікою та зручним UI/UX. Головна мета сервісу — допомогти користувачеві швидко ознайомитися із закладами відпочинку, знайти контакти без зайвих кліків та безпечно організувати компанію для відпочинку.

Додаток адаптований під мобільні пристрої та підкреслює зручність взаємодії користувача, ресторатора та адміністратора платформи.

---

## ⚠️ Попередження при першому запуску (Onboarding)
Для забезпечення безпеки та відповідності законодавству, під час першого візиту додаток показує інтерактивні попередження:
1. **Віковий ценз:** *«Запускаючи цей додаток, ви погоджуєтесь, що вам виповнилося 18 років»*.
2. **Особиста безпека:** *«Адміністрація застерігає вас бути обережними і не зустрічатися з незнайомими людьми в небезпечних чи невідомих вам місцях»*.

## 🛠️ Технологічний стек

### Frontend & Backend
* **Framework:** Next.js (App Router)
* **API Architecture:** Next.js Route Handlers (REST API)
* **Authentication:** JWT (Access & Refresh Tokens)
* **API Documentation:** Swagger / OpenAPI 2.0 (`swagger.json`)

### Database & Infrastructure
* **Database:** MySQL (хостинг у хмарі **Aiven.io**)
* **ORM:** Prisma
* **File Storage:** Збереження та дистрибуція медіафайлів (фото закладів та новин) через хмарне сховище **Amazon S3 (amazonaws.com)**

## 🚀 Функціональні розділи додатка

### 1. 🌍 Користувацький функціонал та навігація
* **Авторизація:** Вхід/Реєстрація через пошту (із заглушками під Google+, Facebook, Google Play, App Store).
* **Головна сторінка:** Перегляд інтерактивного списку всіх верифікованих закладів.
* **Пошук та Розумне сортування:**
    * Миттєвий пошук за назвою.
    * Фільтрація за типом, середнім чеком, тегами та унікальними особливостями (*Wi-Fi, парковка, жива музика*).
    * Сортування за рейтингом, середнім чеком, датою публікації, алфавітом та **віддаленістю від користувача** (формула Гаверсину).
* **Карта та Маршрути:** Можливість побудови швидкого маршруту до обраного закладу.
* **Зворотний зв'язок:** Можливість залишити оцінку, текстовий відгук та прикріпити фото чека для верифікації візиту. Наявність кнопки **«Залишити скаргу»** на сторінці закладу для виявлення нечесних акцій чи обману.
* **Зв'язок:** Форма відправки повідомлення менеджеру закладу (з поштовою заглушкою).

### 2. ⚡ Унікальна функція «Пиячок»
Інноваційний інструмент для швидкого пошуку компанії. На сторінці кожного закладу інтегрована кнопка «Пиячок», яка дозволяє ініціювати зустріч:
* Вибір дати та часу зустрічі.
* Опис мети зустрічі.
* Гнучкі критерії пошуку компаньйонів: *стать, бажана кількість людей, сума витрат та хто оплачує рахунок*.
* Можливість швидкого зв'язку через кнопку «написати мені» (всі сповіщення локалізовані всередині системи).

### 3. 📰 Сторінка новин та Промо
Новини екосистеми розділені на три категорії:
* **Загальні:** Стрічка новин усіх закладів у хронологічному порядку.
* **Акції:** Спеціальні пропозиції від рестораторів.
* **Події:** Анонси вечірок, концертів та дегустацій.
> *(Опціонально реалізована логіка пріоритетного виведення акцій та подій за умови інтеграції платного просування).*

### 4. 🗂️ Особистий кабінет (Режими доступу)

#### А. Звичайний користувач & Менеджер закладу (Ресторатор)
* Керування профілем та вкладка **«Улюблене»**.
* Вкладки **«Мої коментарі»** та **«Мої оцінки»** для відстеження активності.
* Повний цикл CRUD для власних закладів (додавання надходить на модерацію адміну).
* Керування стрічкою новин свого закладу (додавання тексту та фото акцій/подій).
* **Аналітика:** Перегляд статистики переглядів власного закладу у розрізі обраних діапазонів дат (недоступно для звичайних гостей).

#### Б. Супер-Адміністратор (SUPERADMIN)
Панель повного контролю над платформою:
* **Модерація:** Списки закладів, що очікують схвалення перед публікацією.
* **Керування контентом:** Редагування/видалення будь-якого закладу, коментаря, оцінки чи новини.
* **Керування користувачами:** Перегляд списку юзерів, редагування ролей, видалення профілів та функція **прив'язки закладу до іншого користувача**.
* **Глобальні налаштування:** Зміна загальних текстових сторінок проєкту (*«Про нас», «Контакти»*), публікація загальносистемних новин.
* **Глибока аналітика:** Доступ до статистики переглядів усіх локацій у розрізі часу.

## 💻 Локальне розгортання

1. **Клонування репозиторію:**
   ```bash
   git clone [https://github.com/your-username/piyachok.git](https://github.com/your-username/piyachok.git)
   cd piyachok

2. **Встановлення залежностей:** 
    npm install
3. **Налаштування змінних середовища:
   Створіть файл .env у корені проєкту та вкажіть конфігурацію:**

   DATABASE_URL="mysql://YOUR_DB_USER:YOUR_DB_PASSWORD@mysql-f4ad189-piyachok-v1.k.aivencloud.com:18567/defaultdb?ssl-mode=REQUIRED"
   
4. **Синхронізація схеми БД та генерація Prisma Client:**
   npx prisma db push
   npx prisma generate
5. **npx prisma db seed**
   npx prisma db seed
6. **Запуск у режимі розробки:**
   npm run dev
